# Just Built an AI-Powered Mock Interview Platform in 3 Months

Excited to share DevMeet v2.0 - an AI-powered mock interview platform I've been building for the past 3 months. This project pushed me deep into microservices architecture, cloud infrastructure, and real-time communication.

## What is DevMeet?

AI-powered mock interview platform with:
- **AI Interviewer** - Groq Cloud (LLaMA 3 70B, Mixtral 8x7B)
- **Real-time Video Interviews** - WebRTC with LiveKit
- **Code Execution Sandbox** - Docker-based, 7+ languages
- **Instant AI Feedback** - 6-dimensional scoring with PDF reports
- **Analytics Dashboard** - Track progress over time

## Architecture

13 microservices on AWS EC2 with Python (FastAPI), Node.js, Next.js 14, PostgreSQL, Redis, RabbitMQ, Kafka, Elasticsearch. Full CI/CD via GitHub Actions.

## Key Features

DSA, Behavioral, System Design interviews | Real-time code editor | AI proctoring | WebSocket notifications | Payment integration | Full-text search
